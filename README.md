
# Ether&SteamBoys: Legacy - Web App Cooldown

Aplicación web sencilla para tracking de cooldown (tiempo de espera) de habilidades del juego de cartas Ether&SteamBoys: Legacy, para uso como apoyo a jugadores durante las partidas del juego de mesa, en cualquier tipo de dispositivo. 

Permite controlar el uso de las habilidades del personaje, insertando los datos manualmente de dichas habilidades para el seguimiento del cooldown de las mismas turno a turno.

Desplegada mediante GitHub Pages para su uso por parte de los jugadores.
